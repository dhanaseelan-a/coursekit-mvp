CourseKit

Status: Idea / early development

CourseKit is a planned mobile-first platform for creators to publish and sell downloadable PDF courses and for students to access purchased learning materials securely.

Planned features

- Digital PDF course catalog
- Student registration and authentication
- Secure access to purchased materials
- Razorpay payment integration
- Creator/admin dashboard
- AI-powered study assistant using Claude

Proposed technology

- Frontend: React and TypeScript
- Backend: Cloudflare Workers
- Database: Cloudflare D1
- Storage: Cloudflare R2
- Payments: Razorpay

Planned Claude integration

CourseKit aims to use the Claude API to help students ask questions about course materials, understand programming concepts, and receive explanations grounded in their purchased learning content.

The Claude integration has not been implemented yet.

Development roadmap

1. Build the initial landing page.
2. Create a sample course catalog.
3. Develop basic user authentication.
4. Build the course administration interface.
5. Add secure purchases and file delivery.
6. Prototype the AI study assistant.

Current stage

Concept validation and initial development. No commercial launch, active users, or working AI integration are claimed.
